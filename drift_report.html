1 Dataset Overview & Feature Representation

The monitoring pipeline processes transaction records to catch unauthorized card use[cite: 1, 2]:

  • Total Records Evaluated: 284,807 transactions recorded across European cardholders[cite: 2].
  • Class Imbalance: Only 492 transactions are fraudulent (a baseline fraud rate of 0.173%)[cite: 2]. The remaining 99.827% are legitimate transactions[cite: 2].
  • Confidentiality via PCA (V1 to V28): To protect personal user identities, card numbers, merchant IDs, and geographic locations, the raw features are transformed using Principal Component Analysis (PCA) into 28 orthogonal numerical components.
  • Physical Features: Only Time (seconds elapsed since the first transaction in the dataset) and Amount (transaction monetary value) remain in their original units.

3 Reasoning Behind Flagging a Transaction as Fraud

The AI does not make random guesses; it relies on tree-based decision boundaries identifying abnormal multi-dimensional patterns:

  • Severe Component Deviations: Fraudulent transactions consistently display extreme negative or positive outlier values along key latent components (specifically V14, V12, V10, and V4), which correspond to abnormal merchant categories and non-standard device/IP patterns.
  • Amount vs. Velocity Mismatches: Unusually high or micro-testing transaction amounts occurring at high frequencies relative to the Time feature trigger splits that route the transaction into high-fraud-probability decision tree leaves.
  • Ensemble Probability Aggregation: Each decision tree in the 100-tree Random Forest votes on the transaction. When the percentage of trees flagging the pattern crosses 24.0%, the transaction is marked as high-risk and blocked[cite: 2].

5 Why the 0.240 Optimal Threshold Was Selected

Standard machine learning classifiers use a default threshold of 0.50. In fraud detection, this default causes severe financial loss:

Total Cost = (10 × False Negatives) + (1 × False Positives)
  • Cost Asymmetry: A False Negative (missing an actual fraudster) incurs direct financial reimbursement liabilities, chargeback penalties, and customer churn. A False Positive (declining a legitimate cardholder) merely triggers an SMS confirmation or temporary delay.
  • The 10:1 Ratio: Because missing fraud is modeled as 10 times more damaging than a temporary false alarm, the cost function shifts the decision barrier down from 0.50 to 0.240[cite: 2].
  • Result: By lowering the threshold to 0.240, the model catches 85.7% of fraud on validation while producing only 5 false alarms out of tens of thousands of transactions[cite: 2].
